Количественный и качественный химический анализ

Количественный химический анализ предназначен для определения количества известного чистого вещества в смесях (или растворах). В основе такого анализа лежит закон сохранения массы: масса всех веществ, вступающих в химическую реакцию, равна массе всех продуктов реакции.

  • Гравиметрический — точное измерение массы исследуемой пробы и конечного продукта.
  • Титриметрический (объёмный) — измерение количества реактива, который был израсходован в ходе реакции с исследуемым компонентом.
  • Газоволюмометрический — определение объёма компонентов газовой смеси, которые поглощаются при пропускании через специальные реактивы.

Качественный химический анализ предназначен для идентификации (подтверждения) наличия данного вещества в смеси (растворе) и для подтверждения или определения структуры вещества. Обнаружение элементов в составе исследуемого вещества производят, переводя их в соединение, обладающее какими-либо характерными свойствами.

Некоторые методы качественного анализа:

  • Дробный — обнаружение исследуемого компонента с помощью специфического реагента.
  • Систематический — последовательное разделение смеси ионов по аналитическим группам с последующим обнаружением каждого иона по отдельности.

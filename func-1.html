Производные функции

Производная функции — это понятие дифференциального исчисления, которое характеризует скорость изменения функции.

Некоторые факты о производных функций:

  • Знак производной определяется по изначальной функции: если функция возрастает, то производная положительна, если убывает — отрицательна. В точках, где функция не возрастает и не убывает (стационарные точки), производная равна 0.
  • Геометрический смысл производной: если провести касательную к функции в некоторой точке, то производная в этой точке будет равна тангенсу угла её наклона.
  • Физический (механический) смысл производной: производная от функции равняется скорости движения некоторого тела по траектории в момент времени.

Некоторые свойства производных, которые упрощают их вычисление:

  • Производная константы равна нулю: (c)’ = 0.
  • Вынесение константы за знак производной: (c * f(x))’ = c * f’(x).
  • Производная суммы функций равна сумме производных: (f(x) + g(x))’ = f’(x) + g’(x).
  • Производная произведения функций: (f(x) * g(x))’ = f’(x) * g(x) + f(x) * g’(x).
  • Производная частного функций: (f(x) / g(x))’ = (f’(x) * g(x) — f(x) * g’(x)) / g(x)^2.
